# Morion 2.0 releases

Signed installers and the update feed for Morion 2.0, the local notebook with kanban and MCP memory for coding agents.

- Download: the latest release on this page, or https://morion.ai/download
- The app checks this repository for updates and verifies every update with Morion's release signing key before installing it.
- Morion 1.x (Morion Community) is published separately at https://github.com/miksushko/morion-releases and does not update to 2.0.

Support: support@morion.ai
